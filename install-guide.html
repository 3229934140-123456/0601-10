🚀 快速安装

  1. 打开 Chrome 浏览器，在地址栏输入 chrome://extensions/
  2. 开启右上角的「开发者模式」开关
  3. 点击左上角「加载已解压的扩展程序」按钮
  4. 选择本插件所在的文件夹
  5. 安装完成！点击浏览器工具栏中的插件图标即可使用

⚙️ API 配置

  1. 点击插件右上角的「设置」按钮
  2. 在 API 配置中填入您的 API Key
  3. 选择合适的 AI 模型
  4. 设置每日使用额度提醒
  5. 点击「保存设置」即可

💡 提示：未配置 API Key 时，插件将使用演示模式，返回模拟结果用于体验功能。配置真实 API Key 后即可获得真实的 AI 服务响应。
